# 모아 (MOA) — AI 소비 일기

반응형 달력, 지출 분석 도넛 그래프, AI 소비 일기 사이드바를 제공하는 개인용 가계부입니다.

## 사용 기능

- 오늘 지출 / 이번 달 지출 / 남은 월별 예산 / 하루 평균
- 날짜 클릭으로 일별 기록 확인 및 추가·수정·삭제
- 일·주·월 카테고리별 원형 그래프
- 소비 당시 만족/보통/아쉬움/후회와 메모
- 대화형 AI가 지출 후보를 찾아 보여주고, 사용자가 직접 **기록 저장**을 누르면 가계부에 반영

## Render 설정

Python Web Service / build: `echo "No dependencies"` / start: `python server.py`

**환경변수:**
- `OPENAI_API_KEY`: OpenAI Platform에서 발급한 비밀 API 키. **GitHub에 올리지 마세요.**
- `APP_ACCESS_TOKEN`: 사용자가 직접 정한 긴 비밀 문자열. 채팅 API 호출 시 필요합니다.
- `OPENAI_MODEL`: `gpt-4o-mini` (기본값)

보안상 **API 키는 서버에만 저장**되며 브라우저로 내려가지 않습니다. 앱 접속 암호는 채팅 사이드바에서 입력하며, 해당 탭의 sessionStorage에만 보관됩니다. 서비스를 공개 URL로 배포하는 동안 암호를 타인에게 공유하지 마세요.

## 저장과 제약

지출·예산·대화 내역은 브라우저의 localStorage에 저장됩니다. **기기 간 동기화 및 서버 DB는 아직 없습니다.** 다른 기기에서 보면 기록이 다르게 보이며 브라우저 데이터 삭제 시 사라질 수 있습니다. 중요 데이터는 백업 기능과 지속형 DB를 구현한 다음 옮기세요.

AI 기능은 서버 환경변수 두 개가 설정되어야 동작합니다. API 키가 없으면 화면의 달력과 그래프, 수동 지출 기록은 정상적으로 작동하지만 AI 답변은 사용할 수 없습니다.

## 개발

로컬에서 Python 3 설치 후 `python server.py`를 실행하세요. 브라우저에서 `http://localhost:10000` 접속. 별도 패키지 설치는 필요하지 않습니다.
