# 모아 — 나의 하루와 소비

달력과 소비 분석, 소비 감정 기록을 한 화면에서 관리하는 반응형 개인 가계부 웹앱입니다.

## 시작하기

`index.html`을 내려받아 Chrome, Edge, Safari 등 브라우저에서 열면 됩니다. 별도의 설치나 API 키, 서버가 필요하지 않습니다.

## 현재 구현된 기능

- 이번 달 지출 / 남은 예산 / 하루 평균 / 오늘 지출 요약
- 월간 달력의 날짜별 지출 합계 및 일별 상세 기록
- 일·주·월 카테고리별 도넛 그래프
- 지출 추가·수정·삭제, 소비 당시 감정과 메모 기록
- 월별 예산 설정
- 소비 일기 채팅 사이드바 (텍스트 저장 전용, AI 응답 없음)
- 모바일 및 데스크톱 반응형 레이아웃

## 데이터 보관

모든 기록은 현재 브라우저의 `localStorage`에 저장됩니다. 다른 브라우저나 기기와 동기화되지 않으며, 브라우저 저장 데이터를 삭제하면 기록도 사라집니다. 실제 사용 전 장기 보존이 필요하다면 데이터 내보내기/백업 및 서버 DB 연동을 추가하세요.

## AI 기능 예정

대화형 AI API는 미연결입니다. 향후 AI가 대화에서 금액, 소비 항목, 감정을 추출해 사용자의 확인을 거쳐 저장하는 기능을 추가할 수 있습니다.

## 배포

GitHub Pages를 이용하려면 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**에서 `main` 브랜치와 `/(root)` 폴더를 선택하세요. Pages 공개 시 앱 자체는 누구나 접근할 수 있지만, 현재 기록은 각 방문자의 브라우저에만 저장됩니다.
